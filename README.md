# متتبع الاستثمارات - السوق السعودي

تطبيق ويب شامل لتتبع استثماراتك في السوق السعودي (تداول - TASI) بواجهة عربية كاملة.

## المميزات

- **لوحة تحكم** - نظرة شاملة على قيمة المحفظة والأرباح والخسائر
- **إدارة المحافظ** - إنشاء محافظ متعددة وتتبع كل محفظة على حدة
- **تتبع الحيازات** - إضافة وحذف الأسهم مع حساب متوسط سعر الشراء
- **المعاملات** - تسجيل عمليات الشراء والبيع وتوزيعات الأرباح
- **قائمة المراقبة** - متابعة الأسهم مع أسعار مستهدفة
- **أسهم تداول** - تصفح 30+ سهم سعودي مع بيانات السوق
- **التحليلات** - رسوم بيانية لتوزيع القطاعات والأداء الشهري
- **واجهة عربية** - دعم كامل لـ RTL مع خط عربي

## التقنيات

- Next.js 16 (App Router)
- TypeScript
- Prisma 7 + SQLite
- Tailwind CSS 4
- Recharts

## التشغيل

```bash
# تثبيت الحزم
npm install

# إعداد قاعدة البيانات
npx prisma migrate dev
npm run db:seed

# تشغيل التطبيق
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## البيانات

يحتوي التطبيق على بيانات تجريبية لـ 30 سهم سعودي من أسواق تداول، مع محافظ ومعاملات نموذجية. الأسعار محاكاة للأغراض التوضيحية.

## الصفحات

| الصفحة | المسار | الوصف |
|--------|--------|-------|
| لوحة التحكم | `/` | ملخص شامل للاستثمارات |
| المحافظ | `/portfolios` | إدارة المحافظ الاستثمارية |
| تفاصيل المحفظة | `/portfolios/[id]` | حيازات وتوزيع قطاعات |
| الأسهم | `/stocks` | قائمة أسهم تداول |
| المعاملات | `/transactions` | سجل الشراء والبيع |
| قائمة المراقبة | `/watchlist` | أسهم تحت المراقبة |
| التحليلات | `/analytics` | رسوم بيانية وتحليلات |
